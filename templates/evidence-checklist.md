# Evidence Checklist — 合规检查清单

> Agent 在 Stage 7 执行，输出文档前必须逐项确认。

---

## 内容真实性检查

- [ ] 文档中是否出现了虚构的模型参数（Seed / Steps / CFG 具体值）？
  - 如有：删除或标注"未记录"

- [ ] 是否把 Reconstructed Prompt 写成了"原始 Prompt"？
  - 如有：修改措辞，明确标注为"Prompt 复现建议"

- [ ] 文档中所有技术参数是否均来自用户明确提供的信息？
  - 如有推断值写成事实：修正措辞

- [ ] 是否把人工后期内容（PS 修图、排版等）误写成 AI 生成？
  - 如有：修正归属

- [ ] 是否对所有无法确认的信息做了明确处理（留空或注明"未记录"）？

---

## 匿名合规检查

- [ ] 正文中是否包含作者姓名？
- [ ] 正文中是否包含学号？
- [ ] 正文中是否包含学校/学院/院系名称？
- [ ] 正文中是否包含指导教师/导师姓名？
- [ ] 正文中是否包含班级/专业/联系方式等个人信息？
- [ ] Word 文件元数据（作者字段）是否已清空？

> 如赛事不要求匿名，跳过本节。

---

## 格式质量检查

- [ ] 文档是否能正常打开，无乱码？
- [ ] 正文中是否无灰色背景代码框、无蓝字超链接？
- [ ] 是否无英文样式名称残留在中文正文中？
- [ ] 创意说明部分是否不少于 200 字？
- [ ] 是否至少嵌入了 1 张过程图，或说明无截图可提供？
- [ ] 每张图片是否有简短图注？

---

## 内容完整性检查

- [ ] 是否说明了使用的 AI 工具？
- [ ] 是否包含创作过程描述（不只是列工具）？
- [ ] 是否区分了 AI 生成和人工处理的环节？
- [ ] 字数是否符合赛事要求（如有字数限制）？
- [ ] 是否存在明显重复的段落？

---

## 打包检查（如需打包）

- [ ] ZIP 压缩包是否包含说明文档？
- [ ] ZIP 压缩包是否包含全部作品原图？
- [ ] 压缩包能否正常解压？
- [ ] 文件命名是否符合赛事要求？

---

## 检查结果

| 状态 | 含义 |
|---|---|
| ✅ 全部通过 | 可以导出，告知用户 |
| ⚠️ 发现轻微问题 | 自动修正并告知用户 |
| ❌ 发现重大问题 | 停止导出，向用户报告，等待确认 |
