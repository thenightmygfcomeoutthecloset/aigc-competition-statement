# Evidence Checklist — 合规与提交流程检查清单

> Agent 在 Stage 7 执行，导出提交材料前必须逐项严格核验。

---

## 一、版权与知识产权（IP）合规检查

- [ ] 是否存在未获授权的第三方图片或网络摄影素材？
- [ ] 画面中是否出现了非赛事命题的第三方商业商标或品牌 Logo？
- [ ] 后期排版字体是否使用了未授权商业字体？（应优先使用开源免费商用字体）
- [ ] 画面角色是否侵犯知名动漫、影视或游戏专属版权形象？
- [ ] 所使用的模型或 LoRA 是否存在商业/竞赛限制？

**处理准则**：
- 若已具备授权或全原创 → 标记为“已确认原创”；
- 若版权权属未经验证 → **严禁私自标记“无版权争议”**，必须标注为 `Requires User Confirmation（需创作者在提交前确认获得合法授权）`。

---

## 二、提交完整度核查（Submission Check）

逐项检查是否满足比赛文案要求：

- [ ] **最终作品图**：已收到并完成多维度结构化分析
- [ ] **阶段性创作说明**：按阶段完整呈现，非无序碎片罗列
- [ ] **过程视觉材料**：
  - 若宿主具备图像能力：过程图片已真实渲染并保存在项目目录；
  - 若宿主无图像能力：已输出生图指令并标注占位，标记 `⚠️ Required Visual Evidence Missing`。
- [ ] **AIGC 工具环节说明**：各环节工具分工与作用清晰（无虚假 Photoshop 绑定）
- [ ] **必要提示词（Prompts）**：包含原始 Prompt [Verified] 或 具备因果关系的演进 Prompt [Reconstructed]
- [ ] **输入素材（垫图）**：明确说明原创垫图/草图或逆向生成的复现草稿
- [ ] **配置参数**：如实记录真实值或注明建议复现范围（Seed 严禁编造）
- [ ] **对应工具结果说明**：各阶段均说明工具生成效果与阶段性瑕疵原因
- [ ] **人机分工说明**：明确界定 AI 负责部分与人工主导精修部分
- [ ] **版权状态**：已完成自查并标注确认状态
- [ ] **复现材料说明**：包含 Reconstructed 内容时，第七章免责声明完备

> **红线原则**：若宿主无生图工具导致图片未实际生成，必须显式标记 `⚠️ Required Visual Evidence Missing`；若赛事强制要件空白且未重构，标记 `❌ Required Evidence Missing`，严禁谎报“全部通过”！

---

## 三、内容真实性与反伪造检查

- [ ] 是否存在虚构的 Seed 数值或捏造的历史参数？（如有：删除或注明未记录）
- [ ] 是否伪造了 Photoshop / ComfyUI / WebUI 的软件历史界面截图？（如有：坚决删除，严禁以此作为证据）
- [ ] 是否在无证据情况下强加了“Adobe Photoshop 后期图层精修”？（如有：修正为纯 AI 直出说明）
- [ ] 是否把 Reconstructed 内容（垫图/Prompt/阶段图）写成了“原始记录”？（如有：必须修正为复现建议）
- [ ] 是否仅凭视觉分析主观臆测了具体商业模型或 LoRA 名称？（如有：修正为中性技术描述）

---

## 四、匿名合规检查（如赛事要求）

- [ ] 正文中是否包含作者姓名、学号、学校、院系、导师或班级信息？
- [ ] Word 文件属性（author、last_modified_by、company）是否已彻底清空？

---

## 五、排版格式质量检查

- [ ] 文档结构是否遵循 Stage-Centric 闭环（`Input → Tool → Prompt → Parameters → Output → Adjustment`）？
- [ ] 是否无灰色背景代码框、无蓝色超链接、无英文样式名残留？
- [ ] 表格是否清晰单层，无错乱溢出？
- [ ] 每张图片下方是否均有一行规范学术图注？

---

## 最终检查结论分类

| 状态标识 | 含义与处置措施 |
|---|---|
| **✅ 合规通过 (Passed)** | 所有必备要素齐全，过程图片已真实渲染，证据链真实规范，可以生成交付。 |
| **⚠️ 视觉材料待补 (Required Visual Evidence Missing)** | 宿主缺少生图能力，过程图片未实际渲染生成，需创作者依据文档中的生图指令手动补齐。 |
| **⚠️ 需用户确认 (Requires User Confirmation)** | 版权状态或关键信息待创作者在提交前最终核准。 |
| **❌ 缺失必要证据 (Required Evidence Missing)** | 缺少赛事强制要求的核心要件，需补充。 |
| **🛑 发现造假风险 (Hallucination Risk)** | 存在捏造Seed、伪造软件UI截屏或谎称原始Prompt，必须立即更正。 |
