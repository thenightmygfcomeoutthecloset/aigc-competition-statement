# Safety — 真实性、版权合规与反伪造规范

> 本文档定义本 Skill 在真实性原则、素材分类管理、反虚构红线、知识产权审查及合规把关方面的最高准则。

---

## 一、核心原则与底线

本 Skill 旨在帮助创作者**规范、诚实、专业地呈现 AIGC 创作过程**，并在过程材料缺失时**提供合乎学术与工程逻辑的逆向复现材料**。

- **可以做的**：
  - 整理用户真实记录的创作证据；
  - 根据最终作品进行多维度深度画面分析；
  - 推导合理的创作工作流，逆向生成合乎逻辑的早期输入垫图与阶段演进结果（明确标为 [Reconstructed]）；
  - 提供阶段性 Prompt 复现演进与建议配置参数；
  - 严格执行匿名、知识产权与格式合规检查。
- **坚决禁止的（红线）**：
  - **严禁李代桃僵**：绝不得把逆向推测或生成的垫图、阶段图伪装成创作者当时的原始历史记录；
  - **严禁生成虚假软件界面**：绝不得利用 AI 画出假的 Photoshop 图层面板、ComfyUI 节点连线或 WebUI 历史截图来伪造操作证据；
  - **严禁虚构参数**：绝不得凭空编造 Seed、具体模型精确哈希值、参数具体值并当作真实历史填报；
  - **严禁谎称 Prompt**：绝不得把复现 Prompt 写成“创作者当时使用的原始提示词”；
  - **严禁默认绑架工具**：若用户未说明做过后期的单图输入，严禁强加“Adobe Photoshop 后期图层精修”。

## 二、Evidence Levels（证据分级体系与防误标准则）

所有在文档中出现的事实、材料、提示词和参数，必须严格遵循以下四级标准：

| 等级 | 定义 | 文档呈现规范 | 严禁行为 |
|---|---|---|---|
| **[Verified]** | 创作者提供了明确材料证明（原始文件、截图、草图原件、PNG 元数据） | 直接客观陈述事实：“创作者使用本地环境搭建节点工作流生成。” | 严禁将 AI 逆向生成的任何垫图、草稿或阶段图标为 Verified！ |
| **[User-reported]** | 创作者口头说明，但未提供对应原始文件 | 采用引述语气：“据创作者表述，前期进行了手绘草图构思并多次微调参数。” | 创作者未提及的内容严禁以 User-reported 呈现。 |
| **[Reconstructed]** | 基于最终作品由系统逆向推演生成的垫图、阶段稿、Prompt 或参数建议 | 必须显式注明复现性质：“以下内容为逆向复现建议，用于阐明创作演进逻辑，非原始历史记录。” | 严禁省略或淡化复现标注。 |
| **[Unknown]** | 既无真实记录，也无法通过复现确立的信息 | 必须如实标注“未记录”或留空。 | **严禁脑补填充推测值。** |

## 三、禁止生成假软件界面的专项红线

在 Reconstruction Mode 下，系统具备图像生成与编辑能力，但该能力的使用边界有着严格的学术与法律底线：

### 允许生成的视觉材料（标为 [Reconstructed]）：
- 构图草图（铅笔手绘线条风、结构辅助线）
- 轮廓线稿（黑白轮廓、线稿底图）
- 色彩大关系色块图（模糊色块、大笔刷氛围涂抹）
- 阶段性 AI 中间生成图（带有合理阶段缺陷的探索稿）
- 几何体块空间占位稿

### 绝对禁止生成并冒充真实历史的虚假证据：
- ❌ **Photoshop / Illustrator 软件工程界面**：禁止生成带有图层面板、历史记录面板的假截屏；
- ❌ **ComfyUI / SD WebUI 工作流界面**：禁止生成虚假的节点连线截图或任务历史截屏；
- ❌ **Midjourney / 即梦 / 可灵等平台生成历史**：禁止伪造平台生成记录截图；
- ❌ **软件时间线与操作录屏截帧**：禁止伪造剪辑软件时间线；
- ❌ **EXIF / 文件属性截图**：禁止生成虚假的文件详细信息属性截图。

> **原则**：复现的是**作品创作与视觉演进思路**，而不是伪造创作者的**物理电脑操作截屏**！

## 四、人工后期环节的“条件性输出”铁律

许多作品为纯 AI 具象生成直出，并未经过 Photoshop 等软件的复杂分层修整。说明书严禁将“Photoshop 图层精修”作为默认存在的固定阶段：

```text
IF 用户提供了真实后期工程材料 (如 .psd、图层截图、修图过程录屏):
    输出人工后期阶段
    标记具体操作并归为 [Verified]

ELSE IF 用户口头明确说明做过后期精修 (但未提供文件):
    输出人工后期阶段
    标记为 [User-reported]，使用引述语气

ELSE:
    严禁声称使用了 Photoshop！
    严禁伪造 Photoshop 图层工程截图！
    将流程客观描述为“纯 AI 具象生成直出流程”，或注明“本作以 AI 具象渲染为主，未做复杂人工图层修整”。
```

## 五、参数与 Prompt 反伪造规范

1. **参数严禁写死**：
   - 除非有真实元数据证明，否则严禁写死如 `Steps 30, CFG 7.0`；
   - 缺失参数时，一律以范围形式提供推荐复现参数，如：`采样步数：建议范围 25–35 步 [Reconstructed]`；
   - **Seed 种子**：必须填“未记录（建议随机）”，严禁捏造虚假数字。
2. **Prompt 演进因果**：
   - 必须通过“初稿缺陷分析 → 调整意图 → 下一轮 Prompt”呈现因果关系；
   - 统一使用标准格式：`[Reconstructed Prompt | 复现建议]`。

## 六、知识产权（IP）审查规范

高校竞赛对原创与版权纠纷实行“一票否决”。Skill 在生成说明前必须执行知识产权自查：

- **排查项目**：第三方摄影图、非命题商业 Logo、未授权商用字体、知名动漫/游戏/影视角色 IP、专有受限 LoRA。
- **处理准则**：
  - 若版权状态未知或未经验证：**严禁擅自声称“绝对无版权纠纷”**，必须客观标注为：
    `Requires User Confirmation（需创作者在提交前确认获得合法授权）`，并在合规审查中提示创作者自查。

---

## 七、提交流程完整度核查（Submission Check）

在文档生成前必须执行提交审查，包含对单图模式的专项判定：

```markdown
- [ ] 最终作品是否已接收并分析
- [ ] 阶段性过程是否清晰涵盖各阶段
- [ ] 过程视觉图片是否真实渲染就绪
- [ ] 提示词是否具备（真实记录 或 因果演进复现）
- [ ] 输入素材/垫图是否清晰标注类型与等级
- [ ] 参数是否真实或标为建议范围（Seed 无伪造）
- [ ] 知识产权自查是否已完成或标明确认提示
- [ ] 所有 Reconstructed 内容是否均有醒目标签与说明
- [ ] 匿名性检查（正文及文档元数据无个人学校信息）
```

**红线规则**：
- 若宿主 Agent 无生图工具，导致过程图片未实际渲染生成，**严禁显示“全部通过”**，必须明确标记：
  `⚠️ Required Visual Evidence Missing (过程图片未渲染，需创作者补齐)`；
- 若赛事强制要件空白且未重构，必须标记：
  `❌ Required Evidence Missing`。

## 八、复现材料强制说明条款（Disclaimer）

凡在文档中包含任何 `[Reconstructed]` 内容（垫图、阶段图、Prompt、参数建议），文档必须在第七章包含以下标准化免责声明：

> **复现材料特别说明**：  
> 本说明文档中标记为 `[Reconstructed]` 的草图构图、阶段演进过程图、提示词演进及推荐配置参数，系因创作者创作过程中部分原始中间过程文件未作完整留存，由 AI 辅助分析系统根据最终作品的视觉与工程特征进行逆向工程分析和复现构建。其核心目的在于完整展示作品的技术路线、构思演进逻辑与工艺可复现性，并不代表创作当时保存的原始物理历史记录。
