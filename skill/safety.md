# Safety — 真实性与反幻觉规范

> 本文档定义本 Skill 在真实性、诚信和防止信息伪造方面的核心原则。

---

## 核心原则

本 Skill 的用途是帮助创作者**真实、诚实地整理和呈现**其 AI 辅助创作过程。

**可以做的**：
- 帮助用户整理和组织已有的创作信息
- 根据最终作品分析视觉特征（明确标注为推断）
- 提供 Prompt 复现建议（明确标注非原始 Prompt）
- 帮助用户以清晰、专业的方式呈现真实创作过程

**不能做的**：
- 把事后推测伪装成创作历史事实
- 编造或填充未经用户提供的任何技术参数
- 把 Reconstructed Prompt 写成"原始 Prompt"
- 编造模型名称、版本号、工作流节点细节

---

## Evidence Levels 详细说明

### [Verified] — 已验证

**定义**：用户提供了明确的可查证材料（文件、图片、截图、PNG 元数据等）。

**示例**：
- 用户上传了 ComfyUI 工作流截图 → AI 工具使用 [Verified]
- PNG 元数据中包含 Prompt JSON → Prompt [Verified]
- 用户提供了 `.txt` 格式的原始 Prompt → Prompt [Verified]

**文档措辞**：直接陈述。
> "创作过程中使用了 Stable Diffusion XL，在 ComfyUI 中搭建了节点式工作流。"

---

### [User-reported] — 用户自述

**定义**：用户明确告知，但未提供材料佐证。

**示例**：
- 用户说"我用了 SDXL"但没有截图 → 工具 [User-reported]
- 用户说"大概迭代了十几次"但没有记录 → 迭代次数 [User-reported]

**文档措辞**：使用引述语气，但不需要在最终文档中显示英文标签。
> "据创作者表述，本作品使用 ComfyUI + SDXL 作为主要生成工具，并进行了多轮迭代调整。"

---

### [Reconstructed] — 复现推断

**定义**：Agent 根据最终作品图的视觉特征分析推断，不是对历史事实的还原。

**示例**：
- 根据作品画面风格生成 Prompt 复现建议
- 根据画面色调推断使用了某类风格控制
- 根据细节纹理推断可能使用了某类模型

**文档措辞**：明确标注为复现建议，而不是历史事实。
> "以下 Prompt 复现建议基于最终作品的视觉特征生成，用于帮助复现相似视觉方向，并非创作时实际使用的原始提示词："
> ```
> (masterpiece, best quality:1.2), cinematic lighting, ...
> ```

**绝对禁止**：
> ❌ "创作时使用的原始 Prompt 为：(masterpiece, best quality:1.2)..."  
> ❌ "当时的提示词是：..."

---

### [Unknown] — 未知

**定义**：该信息用户未提及，也无法从材料中推断。

**文档处理**：

| 情况 | 处理方式 |
|---|---|
| 非关键字段 | 直接省略该字段 |
| 赛事要求必填字段 | 标注"该参数未记录"，告知用户 |
| 用户询问 | 解释无法确认，提供参考范围（不填入文档） |

## 禁止编造清单

以下内容**严格禁止**由 Agent 自动生成，除非用户明确提供：

| 信息类型 | 原因 |
|---|---|
| Seed 数值 | 用于唯一标识生成结果，编造无意义且易被核查 |
| 具体 Steps 数值 | 不同版本工具默认值不同，编造易产生矛盾 |
| 具体 CFG 数值 | 同上 |
| 具体 Sampler 名称 | 同上 |
| 模型完整文件名 | 编造版本号可能指向不存在的模型 |
| LoRA 权重 | 编造权重值会产生错误信息 |
| 创作日期 | 无法推断，且涉及版权时间戳 |
| 软件版本号 | 无法推断 |
| 生成次数 | 无法推断 |
| 工作流节点细节 | 无截图无法描述，描述可能不准确 |
| 截图内容 | 未收到截图不得虚构 |

## Prompt Reconstruction（Prompt 复现）专项规范

### 定义

**Prompt 复现（Prompt Reconstruction）**：
> 根据最终视觉结果生成一组能够帮助复现相似视觉方向的提示词。

**不是**：
> 恢复或还原创作者当时真实使用过的原始提示词。

### 使用场景

只在以下情况执行 Prompt 复现：
- 用户明确说明没有保存原始 Prompt
- 用户主动请求"帮我重新生成 Prompt 描述"

### 在文档中的呈现方式

```markdown
## Prompt 复现建议

以下提示词基于最终作品的视觉分析生成，用于帮助复现相似视觉方向。
创作时使用的原始提示词已不可考。

**正向 Prompt（复现参考）**：
(masterpiece, best quality:1.2), [基于作品分析生成的描述]

**负向 Prompt（复现参考）**：
[基于作品风格生成的排除词]
```

### 严格禁止的措辞

```
❌ "创作时使用的原始 Prompt 为……"
❌ "当时的提示词是……"
❌ "实际使用的提示词……"
❌ "经过分析，该作品使用了以下提示词……"（未说明是复现的情况下）
```

## 匿名合规检查

在导出前必须执行：

### 正文检查

扫描以下关键词，发现后告知用户删除：
```python
sensitive_keywords = [
    '姓名', '学号', '学院', '院系', '学校', '大学', '学院',
    '指导教师', '导师', '班级', '专业', '联系方式', '邮箱', '电话'
]
```

### 元数据检查

清空 Word 文件 `core_properties`：
```python
from docx import Document
doc = Document('output.docx')
props = doc.core_properties
props.author = ""
props.last_modified_by = ""
props.company = ""
props.comments = ""
doc.save('output.docx')
```

### 告知用户

如赛事要求匿名，生成完成后主动提示用户：
> "本文档已执行匿名检查，未发现明显个人信息。建议您在提交前再次手动确认文档中无姓名、学号或学校信息。"
