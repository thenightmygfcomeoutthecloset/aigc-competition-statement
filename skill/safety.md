# Safety — 真实性、版权合规与反伪造规范

> 本文档定义本 Skill 在真实性原则、素材分类管理、反虚构红线、知识产权审查及合规把关方面的最高准则。

---

## 一、核心原则与底线

本 Skill 旨在帮助创作者**规范、诚实、专业地呈现 AIGC 创作过程**，或在过程材料缺失时**提供合乎学术与工程逻辑的逆向复现材料**。

- **可以做的**：
  - 整理用户真实记录的创作证据；
  - 根据最终作品进行多维度深度画面分析；
  - 推导合理的创作工作流，逆向生成合乎逻辑的早期输入垫图与阶段演进结果（明确标为 Reconstructed）；
  - 提供阶段性 Prompt 复现演进与建议配置参数；
  - 严格执行匿名、知识产权与格式合规检查。
- **坚决禁止的（红线）**：
  - **严禁李代桃僵**：绝不得把逆向推测或生成的垫图、阶段图伪装成创作者当时的原始历史记录；
  - **严禁虚构参数**：绝不得凭空编造 Seed、具体模型精确哈希值、LoRA 权重并当作真实历史填报；
  - **严禁谎称 Prompt**：绝不得把复现 Prompt 写成“创作者当时使用的原始提示词”；
  - **严禁盲目臆测模型**：不得仅凭画面视觉效果断定使用了某某具体商业模型或私有工作流。

---

## 二、Evidence Levels（证据分级体系）

所有在文档中出现的事实、材料、提示词和参数，必须严格遵循以下四级标准：

| 等级 | 定义 | 文档呈现规范 |
|---|---|---|
| **[Verified]** | 创作者提供了明确材料证明（原始文件、截图、草图原件、PNG 元数据） | 直接客观陈述事实：“创作者使用本地 ComfyUI 搭建节点工作流生成。” |
| **[User-reported]** | 创作者口头说明，但未提供对应原始文件 | 采用引述语气：“据创作者表述，前期进行了手绘草图构思并多次微调参数。” |
| **[Reconstructed]** | 基于最终作品由系统逆向推演生成的垫图、阶段稿、Prompt 或参数建议 | 必须显式注明复现性质：“以下内容为逆向复现建议，用于阐明创作演进逻辑，非原始历史记录。” |
| **[Unknown]** | 既无真实记录，也无法通过复现确立的信息 | 必须如实标注“未记录”或留空，**严禁脑补填充推测值**。 |

---

## 三、输入素材与垫图分类管理规范（Asset Taxonomy）

所有输入素材必须归入以下标准类型，并标明来源属性与证据等级：

1. `user-provided input`（用户原始素材）：创作者实拍照片、赛事官方提供的品牌素材包（[Verified]）。
2. `original sketch`（原创手绘草图）：创作者在纸质或数位板上绘制的构图与线稿原稿（[Verified]）。
3. `original reference`（原始参考图）：创作者在创作初期实际使用的参考图片（[Verified] 或 [User-reported]）。
4. `reconstructed sketch`（逆向复现草图）：由系统根据最终作品结构逆向生成的构图/线稿草稿，用于体现构图探索（[Reconstructed]）。
5. `reconstructed reference`（逆向复现参考）：由系统逆向提取的色彩大关系或局部风格参考（[Reconstructed]）。
6. `previous-stage output`（上一阶段输出）：上一生成阶段产出的中间态图像，作为下一阶段的图生图/局部重绘输入（[Reconstructed] 或 [Verified]）。

---

## 四、Prompt 与参数反伪造红线

### 1. 提示词记录规范
- **真实记录存在时**：直接完整摘录正向与负向 Prompt，归为 `[Verified]`。
- **真实记录缺失时**：生成阶段性 Prompt（V1/V2/V3），说明每次调整的优化目标（如构图定型、光影强化、材质深化、负向排除），并统一冠以：
  `【Reconstructed Prompt（复现建议）】`
- **严禁出现的表述**：
  ❌ “当时实际使用的提示词为……”
  ❌ “创作现场记录的原始 Prompt 如下……”

### 2. 生成参数记录规范
- 只有创作者明确提供或元数据中提取出的参数，才能作为历史事实写入。
- 缺失参数时，统一归入《推荐复现参数》，并声明：
  “以下参数为基于作品视觉效果给出的建议复现配置，仅供复现相似视觉效果参考，非创作者现场历史记录。”
- **随机种子（Seed）**：无真实记录时必须填“未记录（建议随机值）”，严禁编造诸如 `Seed: 482910385` 等虚假数值。

## 五、版权与知识产权（IP）审查规范

高校创意竞赛与 AIGC 赛事对版权要求极其严苛。Skill 在生成说明前必须执行版权风险自查：

### 1. 风险排查清单
- **第三方图像与摄影**：是否使用了未获授权的网络实拍图、图库素材？
- **商业标识与 Logo**：是否包含除赛事命题品牌外的其他第三方商标或商业 Logo？
- **字体版权**：后期文字排版是否使用了非开源免费可商用字体？
- **知名角色 IP**：是否侵犯了知名动漫、影视、游戏受版权保护的角色形象？
- **专有模型与 LoRA**：使用的 LoRA 是否有明确商业/竞赛参赛限制协议？

### 2. 处理规则
- 若创作者已提供原创证明或赛事官方授权 → 标注为 `已确认合规`。
- 若版权状态未知或无法证明 → **绝对不得代创作者声称“本作品完全无知识产权争议”**，必须客观标注为：
  `Requires User Confirmation（需创作者在提交前确认获得合法授权）`，并在合规报告中提醒创作者自查。

## 六、提交流程完整度审查（Submission Check）

在最终导出 Word 文档前，必须对照赛事要求进行逐项检查：

```markdown
- [ ] 最终作品是否已接收并分析
- [ ] 阶段性创作过程是否清晰涵盖各阶段（构思 → 初稿 → 迭代 → 后期）
- [ ] 阶段结果图与图注是否完整
- [ ] AIGC 工具在各环节的分工是否清晰
- [ ] 提示词是否具备（原始记录 或 规范标明的复现演进）
- [ ] 输入素材/垫图是否说明（原始素材 或 规范标明的逆向草稿）
- [ ] 参数是否如实填报（或注明复现建议）
- [ ] AI 生成与人工后期的边界职责是否切分清晰
- [ ] 知识产权自查是否已完成或标明确认提示
- [ ] 所有 Reconstructed 内容是否均有醒目标签与说明
- [ ] 匿名性检查（正文及文档元数据无个人学校信息）
```

**红线提示**：若赛事强制要求某项材料（例如垫图或 Prompt），但当前仍彻底缺失且未启用重构补齐，系统必须明确报错：
`⚠️ Required Evidence Missing（缺少赛事强制要求的必要证据材料）`，并列出缺失清单，绝不能虚假宣称文档已完美合规。

---

## 七、复现材料强制说明条款（Disclaimer）

凡在文档中包含任何 `[Reconstructed]` 内容（垫图、阶段图、Prompt、参数建议），文档必须在第七章包含以下标准化免责声明：

> **复现材料特别说明**：  
> 本说明文档中标记为 `[Reconstructed]` 的草图构图、阶段演进过程图、提示词演进及推荐配置参数，系因创作者创作过程中部分原始中间过程文件未作完整留存，由 AI 辅助分析系统根据最终作品的视觉与工程特征进行逆向工程分析和复现构建。其核心目的在于完整展示作品的技术路线、构思演进逻辑与工艺可复现性，并不代表创作当时保存的原始物理历史记录。
