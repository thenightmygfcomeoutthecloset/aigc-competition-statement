# Output Specification — Word 文档格式与阶段证据链规范

> 本文档定义本 Skill 生成的 Word（.docx）说明书的排版标准与 Stage-Centric 结构规范。

---

## 核心设计哲学

**严谨、学术、自洽、完整可直接提交。**

- 生成的说明文档必须呈现出严密、自洽的工程与设计演进证据链；
- **无悬挂占位**：图文紧密呼应，提示词、参数、图注全量填充，绝不留下“待补齐”、“待确认”等阻断性占位；
- 严禁出现任何未经处理的代码框底色或 AI 廉价排版痕迹。

---

## 严禁出现的排版瑕疵

| 违规项 | 评委体感 | 正确规范 |
|---|---|---|
| **灰色背景代码框** | “直接复制 ChatGPT 结果未排版” | 正文一律采用标准段落样式，代码和 Prompt 采用正文左缩进宋体/仿宋，标题手动加粗 |
| **蓝色超链接带下划线** | “网文拼凑感强，不严肃” | 去除蓝色与下划线，保留黑色纯文本引用 |
| **多层嵌套复杂表格** | 跨 Word/WPS 版本容易错乱折叠 | 采用干净的单层三线表或标准单层表格，边框清晰 |
| **虚构 Photoshop 阶段** | “作品明显为纯生图，却强行编造PS图层操作” | 遵循条件性输出：无后期证据时如实描述为纯生图直出流程 |
| **写死具体假参数** | “明明没有原始数据却写了具体的步数与种子” | 采用工具自适应建议范围（如 25–35 步 [Reconstructed]），Seed 标为未记录 |
| **工具不支持硬造负向词** | “DALL-E 格式中硬塞 Negative Prompt” | 严格适配工具特性，工具无负向词项则直接省略 |

## 页面版式与字号规范

- **纸张**：A4 纵向，页边距常规（上下 2.54cm，左右 3.18cm）
- **文档总标题**：小二号（18pt），黑体，加粗，居中
- **一级标题（一、二、三...）**：小三号（15pt），黑体，加粗，段前段后 0.5 行
- **二级标题（1. 2. 3...）**：四号（14pt），黑体/楷体，加粗
- **三级标题**：小四号（12pt），宋体，加粗
- **正文**：五号（10.5pt）或小四号（12pt），宋体/仿宋，1.25–1.5 倍行距，首行缩进 2 字符
- **图表与图注**：小五号（9pt），楷体，居中，紧随图表下方

## Stage-Centric 标准文档结构（七大章节）

```text
【作品名称】AIGC 创作过程说明书

一、 作品基本信息
   - 作品名称、参赛赛事、作品类型（平面海报/概念插画/三维渲染/影视原画）
   - 核心创作主题与主旨
   - 采用的 AIGC 核心技术路径（区分原始创作推断与复现工具）

二、 创作构思与立意
   - 创作背景与选题动机（立意溯源、与赛事主题的结合点）
   - 视觉设计思路（色彩倾向、构图逻辑、光影构想）
   - 预期设计目标与人机协同目的

三、 阶段性创作过程（核心证据链，基于 Dynamic Stage Graph 动态展开）
   * 严格遵循 Input → Tool → Prompt → Parameters → Output → Adjustment 闭环 *

   3.1 阶段一：概念构思与构图规划
       - 创作目的：确立视觉大骨架与空间构图
       - 输入素材：[原创草图] 或 [Reconstructed 逆向构图草稿]（标明素材类型与来源）
       - 使用工具：手绘软件 / 构图设计工具
       - 提示词：[Reconstructed Prompt | 复现建议]
       - 推荐参数：画幅比例基准
       - 阶段结果：图 1 构图线稿/占位草图（附规范学术图注）
       - 调整说明：评估阶段一结果，确定下一阶段需要通过 AI 具象化的方向

   3.2 阶段二：AIGC 基础生成与初稿输出
       - 创作目的：将构图转化为具备色彩与光影关系的具象画面
       - 输入素材：阶段一构图稿作为参考输入（垫图）
       - 使用工具：AI 图像生成工具
       - 提示词：[Reconstructed Prompt | 复现建议]（涵盖主体形态与环境基调）
       - 配置参数：工具自适应参数范围（Seed 标为未记录）
       - 阶段结果：图 2 AI 生成第一版初稿图像（呈现真实阶段演进感，附规范图注）
       - 调整说明：客观比对初稿与最终成图的演进差距，阐明下一轮提示词优化的针对性意图

   3.3 阶段三：Prompt 迭代与视觉深化
       - 创作目的：针对阶段二演进差距，深化光效与细节质感
       - 输入素材：上一阶段输出图作为迭代参考底图
       - 使用工具：AI 迭代与优化工具
       - 提示词：[Reconstructed Prompt | 复现建议]（深化细节光效，负向排除杂斑）
       - 配置参数：工具自适应重绘参数
       - 阶段结果：图 3 迭代深化后的成果（附规范图注）
       - 调整说明：确认 AI 具象生成阶段完成

   3.4 阶段四：人工后期精修与整合排版（条件性输出环节）
       - 【条件性输出原则】：
         - 有真实后期材料 → 输出后期具体操作，标记 [Verified]；
         - 口述做过后期 → 输出引述记录，标记 [User-reported]；
         - 无任何后期证据 → 如实说明“本项目以纯 AI 具象生成直出为主，未进行复杂人工图层修整”，严禁强加 PS 截图。

四、 AIGC 工具使用说明与人机协同分工
   - 表格化呈现全流程工具链与各环节作用
   - 明确界定“AI 负责的创作部分”与“人工主导的创作部分”，凸显人类主观能动性与创作者控制力

五、 全流程 Prompt、输入素材与参数汇总表
   - 单层综合大表，将各阶段的 Input、Tool、Prompt、Parameters、Output 一览式完整关联汇总

六、 版权、素材来源与原创性说明
   - 输入素材合法来源陈述，完成知识产权自查，声明内容积极向上

七、 复现材料特别说明（若存在 Reconstructed 内容时必带）
   - 标准学术免责声明，明确复现材料用于完整呈现创作逻辑与技术可复现性
```

## 导出与元数据清理

在最终交付 `.docx` 文件时，必须通过脚本清空文档元数据：
- `author = ""`
- `last_modified_by = ""`
- `company = ""`
- `comments = ""`
