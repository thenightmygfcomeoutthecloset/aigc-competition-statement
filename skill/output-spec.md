# Output Specification — Word 文档格式与阶段证据链规范

> 本文档定义本 Skill 生成的 Word（.docx）说明书的排版标准与 Stage-Centric 结构规范。

---

## 核心设计哲学

**严谨、学术、符合高校竞赛与评审规范。**

- 生成的说明文档应当呈现出严密、可验证的工程与设计证据链。
- 严禁出现任何未经处理的 Markdown 杂质或廉价 AI 排版痕迹。

---

## 严禁出现的排版瑕疵

| 违规项 | 评委体感 | 正确规范 |
|---|---|---|
| **灰色背景代码框** | “直接复制 ChatGPT 结果未排版” | 正文一律采用标准段落样式，代码和 Prompt 采用正文左缩进宋体/仿宋，标题手动加粗 |
| **蓝色超链接带下划线** | “网文拼凑感强，不严肃” | 去除蓝色与下划线，保留黑色纯文本引用 |
| **多层嵌套复杂表格** | 跨 Word/WPS 版本容易错乱折叠 | 采用干净的单层三线表或标准单层表格，边框清晰 |
| **纯截图罗列无证据链** | “无法看出每步工具和参数是怎么来的” | 严格遵循 `Input → Tool → Prompt → Parameters → Output → Adjustment` 阶段推进闭环 |
| **英文样式名残留** | 导出时夹带 Heading 1 等英文字样 | 统一使用标准中文样式名（标题 1、标题 2、正文） |

---

## 页面版式与字号规范

- **纸张**：A4 纵向，页边距常规（上下 2.54cm，左右 3.18cm）
- **文档总标题**：小二号（18pt），黑体，加粗，居中
- **一级标题（一、二、三...）**：小三号（15pt），黑体，加粗，段前段后 0.5 行
- **二级标题（1. 2. 3...）**：四号（14pt），黑体/楷体，加粗
- **三级标题**：小四号（12pt），宋体，加粗
- **正文**：五号（10.5pt）或小四号（12pt），宋体/仿宋，1.25–1.5 倍行距，首行缩进 2 字符
- **图表与图注**：小五号（9pt），楷体，居中，紧随图表下方

## Stage-Centric 标准文档结构（七大章节）

文档必须严格按照以下阶段递进大纲组织：

```text
【作品名称】AIGC 创作过程说明书

一、 作品基本信息
   - 作品名称、参赛赛事、作品类型（平面海报/数字插画/三维渲染/视频原画）
   - 核心创作主题与主旨
   - 采用的 AIGC 核心技术路径（如：图生图线稿控制 / 文生图深度迭代 / 分层多模型合成）

二、 创作构思与立意
   - 创作背景与选题动机（立意溯源、与赛事主题的结合点）
   - 视觉设计思路（色彩倾向、构图逻辑、光影构想）
   - 预期设计目标与人机协同目的

三、 阶段性创作过程（核心证据链）
   * 采用 Input → Tool → Prompt → Parameters → Output → Adjustment 闭环 *

   3.1 阶段一：概念探索与构图规划
       - 创作目的：确立视觉大骨架与空间构图
       - 输入素材：[原创草图] 或 [Reconstructed 逆向构图草稿]（标明素材类型与来源）
       - 使用工具：手绘软件 / 构图设计工具
       - 提示词：初始概念关键词 / Prompt V1（标明真实或复现）
       - 推荐参数：基础配置
       - 阶段结果：图 1 构图线稿/占位草图（附规范图注）
       - 调整说明：评估阶段一结果，确定下一阶段需要通过 AI 强化的方向

   3.2 阶段二：AIGC 基础生成与初稿输出
       - 创作目的：实现视觉概念的具体化具象生成
       - 输入素材：阶段一构图稿作为参考输入（ControlNet / 垫图）
       - 使用工具：AI 图像生成工具（如 ComfyUI / Midjourney / SD / Flux）
       - 提示词：Prompt V2（详细正向与环境描述）
       - 配置参数：采样步数、CFG、尺寸、模式（真实值或建议复现值）
       - 阶段结果：图 2 AI 生成第一版初稿（附规范图注）
       - 调整说明：分析初稿存在的具体问题（如光影欠缺、局部形变、色彩偏差）

   3.3 阶段三：Prompt 迭代与视觉深化
       - 创作目的：修正阶段二缺陷，增强细节层次与材质质感
       - 输入素材：上一阶段输出图作为局部重绘或精炼底图
       - 使用工具：AI 迭代与局部控制工具
       - 提示词：Prompt V3（强化光效材质，加入负向提示词剔除杂乱元素）
       - 配置参数：重绘幅度、优化参数
       - 阶段结果：图 3 迭代优化后的高清成品图（附规范图注）
       - 调整说明：确认 AI 生成阶段完成，指出需要人工后期精修的要点

   3.4 阶段四：人工后期精修与整合排版
       - 创作目的：修复 AI 细微瑕疵、色彩全局校准、图层合成与字体排版
       - 输入素材：阶段三生成的最终 AI 渲染图
       - 使用工具：Adobe Photoshop / Illustrator 等图形处理软件
       - 提示词与参数：不适用（人工数字制作环节）
       - 阶段结果：图 4 后期图层面板截图与最终合成效果（附规范图注）
       - 调整说明：完成最终提交版本

四、 AIGC 工具使用说明与人机协同分工
   - 表格化呈现全流程工具链与各环节作用
   - 明确界定“AI 负责的创作部分”与“人工主导的创作部分”，凸显人类主观能动性与创作者控制力

五、 全流程 Prompt、输入素材与参数汇总表
   - 单层综合大表，将各阶段的 Input、Tool、Prompt、Parameters、Output 一览式完整关联汇总

六、 版权、素材来源与原创性说明
   - 输入素材（实拍/手绘/垫图）合法来源陈述
   - 知识产权与第三方元素自查结论（已确认原创 或 Requires User Confirmation 提示）
   - 作品内容积极向上、无违法违规承诺

七、 复现材料特别说明（若存在 Reconstructed 内容时必带）
   - 官方标准免责声明，明确复现材料的逆向技术分析性质，维护学术严谨性
```

## 导出与元数据清理

在最终交付 `.docx` 文件时，必须通过脚本清空文档元数据：
- `author = ""`
- `last_modified_by = ""`
- `company = ""`
- `comments = ""`
