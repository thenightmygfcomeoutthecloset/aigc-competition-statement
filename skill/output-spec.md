# Output Specification — Word 文档格式与阶段证据链规范

> 本文档定义本 Skill 生成的 Word（.docx）说明书的排版标准与 Stage-Centric 结构规范。

---

## 核心设计哲学

**严谨、学术、符合高校竞赛与评审规范。**

- 生成的说明文档应当呈现出严密、可验证的工程与设计证据链。
- 严禁出现任何未经处理的 Markdown 杂质或廉价 AI 排版痕迹。

---

## 严禁出现的排版瑕疵

| 违规项 | 评委体感 | 正确规范 |
|---|---|---|
| **灰色背景代码框** | “直接复制 ChatGPT 结果未排版” | 正文一律采用标准段落样式，代码和 Prompt 采用正文左缩进宋体/仿宋，标题手动加粗 |
| **蓝色超链接带下划线** | “网文拼凑感强，不严肃” | 去除蓝色与下划线，保留黑色纯文本引用 |
| **多层嵌套复杂表格** | 跨 Word/WPS 版本容易错乱折叠 | 采用干净的单层三线表或标准单层表格，边框清晰 |
| **纯截图罗列无证据链** | “无法看出每步工具和参数是怎么来的” | 严格遵循 `Input → Tool → Prompt → Parameters → Output → Adjustment` 阶段推进闭环 |
| **假想默认的 Photoshop 阶段** | “作品看起来是纯生图，却强行编造PS图层操作” | 遵循条件性输出：无后期证据时客观描述为纯生图直出，严禁强加 PS 截图 |
| **写死具体参数** | “明明没有原始数据却写了具体的步数种子” | 采用建议复现范围（如 25–35 步 [Reconstructed]）或如实写未记录 |

## 页面版式与字号规范

- **纸张**：A4 纵向，页边距常规（上下 2.54cm，左右 3.18cm）
- **文档总标题**：小二号（18pt），黑体，加粗，居中
- **一级标题（一、二、三...）**：小三号（15pt），黑体，加粗，段前段后 0.5 行
- **二级标题（1. 2. 3...）**：四号（14pt），黑体/楷体，加粗
- **三级标题**：小四号（12pt），宋体，加粗
- **正文**：五号（10.5pt）或小四号（12pt），宋体/仿宋，1.25–1.5 倍行距，首行缩进 2 字符
- **图表与图注**：小五号（9pt），楷体，居中，紧随图表下方

## Stage-Centric 标准文档结构（七大章节）

文档必须严格按照以下阶段递进大纲组织：

```text
【作品名称】AIGC 创作过程说明书

一、 作品基本信息
   - 作品名称、参赛赛事、作品类型（平面海报/概念插画/三维渲染/影视原画）
   - 核心创作主题与主旨
   - 采用的 AIGC 核心技术路径（如：构图草图引导图生图 / 概念文生图多轮迭代 / 纯 AI 具象生成直出）

二、 创作构思与立意
   - 创作背景与选题动机（立意溯源、与赛事主题的结合点）
   - 视觉设计思路（色彩倾向、构图逻辑、光影构想）
   - 预期设计目标与人机协同目的

三、 阶段性创作过程（核心证据链）
   * 必须严格按照 Input → Tool → Prompt → Parameters → Output → Adjustment 闭环 *

   3.1 阶段一：概念探索与构图规划
       - 创作目的：确立视觉大骨架与空间构图
       - 输入素材：[原创草图] 或 [Reconstructed 逆向构图草稿]（标明素材类型与来源）
       - 使用工具：手绘软件 / 构图设计工具
       - 提示词：[Reconstructed Prompt | 复现建议]
       - 推荐参数：基础画幅比例
       - 阶段结果：图 1 构图线稿/占位草图（附规范图注）
       - 调整说明：评估阶段一结果，确定下一阶段需要通过 AI 强化的方向

   3.2 阶段二：AIGC 基础生成与初稿输出
       - 创作目的：实现视觉概念的具象生成
       - 输入素材：阶段一构图草稿作为参考输入（ControlNet / 垫图）
       - 使用工具：AI 图像生成工具
       - 提示词：[Reconstructed Prompt | 复现建议]（详细正向与环境描述）
       - 配置参数：采样步数范围、CFG 范围、模式（Seed 标为未记录）
       - 阶段结果：图 2 AI 生成第一版初稿（带有合理阶段性瑕疵，附规范图注）
       - 调整说明：明确分析初稿存在的具体问题（如光影欠缺、局部形变、色彩偏差）

   3.3 阶段三：Prompt 迭代与视觉深化
       - 创作目的：修正阶段二缺陷，增强细节层次与材质质感
       - 输入素材：上一阶段输出图作为局部重绘或精炼底图
       - 使用工具：AI 迭代与局部控制工具
       - 提示词：[Reconstructed Prompt | 复现建议]（强化光效材质，引入负向提示词）
       - 配置参数：重绘幅度范围、优化参数
       - 阶段结果：图 3 迭代优化后的高清渲染图（附规范图注）
       - 调整说明：确认 AI 生成阶段完成

   3.4 阶段四：人工后期精修与整合排版（条件性输出环节）
       - 【条件性输出原则】：
         - 有真实后期材料 → 输出后期具体操作，标记 [Verified]；
         - 口述做过后期 → 输出引述记录，标记 [User-reported]；
         - 无任何后期证据 → 严禁编造 Photoshop 图层操作，如实说明“本项目以 AI 具象生成直出为主，未进行复杂人工图层修整”或省略本阶段。

四、 AIGC 工具使用说明与人机协同分工
   - 表格化呈现全流程工具链与各环节作用
   - 明确界定“AI 负责的创作部分”与“人工主导的创作部分”，凸显人类主观能动性与创作者控制力

五、 全流程 Prompt、输入素材与参数汇总表
   - 单层综合大表，将各阶段的 Input、Tool、Prompt、Parameters、Output 一览式完整关联汇总

六、 版权、素材来源与原创性说明
   - 输入素材（实拍/手绘/垫图）合法来源陈述
   - 知识产权与第三方元素自查结论（已确认原创 或 Requires User Confirmation 提示）
   - 作品内容积极向上承诺

七、 复现材料特别说明（若存在 Reconstructed 内容时必带）
   - 标准免责声明，明确复现材料的逆向技术分析性质，维护学术严谨性
```

## 导出与元数据清理

在最终交付 `.docx` 文件时，必须通过脚本清空文档元数据：
- `author = ""`
- `last_modified_by = ""`
- `company = ""`
- `comments = ""`
