# Output Spec — 输出格式规范

> 定义本 Skill 所有输出物的格式标准。

---

## 主文档：AIGC 创作过程说明书

### 文件格式

- 格式：Microsoft Word `.docx`
- 生成工具：python-docx
- 命名规范：`{作品名}_{赛事简称}_AIGC说明书.docx`

### 视觉格式要求

**允许**：
- Word 内置标准字体（宋体、黑体、微软雅黑）
- 手动加粗的标题
- 黑色正文文字，白色背景
- 标准表格（无特殊边框样式）

**禁止**：
- 灰色背景代码块（markdown 风格）
- 蓝色超链接字体
- 英文样式名称出现在中文正文（如 `(Heading 1)` 等）
- 边框阴影、浮动框
- 嵌套表格

## 文档结构模板

```
一、 创意阐释与设计逻辑

  1. 创作背景与选题动机
     — 为什么选这个主题
     — 与赛事主题的契合点

  2. 视觉设计逻辑
     — 风格选择的理由
     — 构图与色彩策略

二、 AI 辅助创作说明

  1. 工具链说明
     — 使用的 AI 工具（逐一列出）
     — 各工具在流程中的具体角色

  2. 提示词记录
     — 原始 Prompt（如有）：完整引用
     — Prompt 复现建议（如无原始）：明确标注来源为视觉分析重构

  3. 参数记录（如有）
     — 仅填写用户明确提供的参数
     — 未知参数留空或注明"未记录"

  4. 创作过程说明
     — 生成环节描述
     — 迭代与调整过程（如有记录）

  5. 人机协同说明
     — AI 负责的创作环节
     — 人工负责的创作环节
     — 如用户未说明比例，不写具体百分比

三、 创作过程证明材料

  — 过程截图（有则嵌入，无则说明）
  — 工作流截图（有则嵌入）
  — 后期软件截图（有则嵌入）
  — 每张图下方附一行图注
```

## Prompt 复现建议输出格式

```markdown
## Prompt 复现建议（基于视觉分析）

> 以下提示词根据最终作品的视觉特征生成，用于帮助复现相似视觉方向。
> 创作时使用的原始提示词已不可考，以下内容为分析重构，非原始记录。

**正向 Prompt（复现参考）**：
(masterpiece, best quality:1.2), [风格], [主体], [场景], [光影], [色彩]

**负向 Prompt（复现参考）**：
low quality, worst quality, text, watermark, [针对当前风格的排除词]
```
