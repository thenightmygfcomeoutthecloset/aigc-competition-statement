# Reconstruction Mode — 逆向重构规范

> 本文档定义在用户**仅提供最终作品图**或**过程材料严重缺失**时，Skill 如何自动逆向重构合理的 AIGC 创作流程、生成必要的复现素材、阶段结果、Prompt 演进与参数建议。

---

## 一、模式定义与触发机制

### 1. 双模式路由

Skill 在接收用户输入后自动判定工作模式：

| 模式 | 触发条件 | 核心策略 |
|---|---|---|
| **Evidence Mode（真实证据模式）** | 用户提供了原始 Prompt、垫图、参数、工作流截图、分层文件等 | 直接整理真实证据，严谨分级，**不生成不必要的替代材料**。 |
| **Reconstruction Mode（逆向重构模式）** | 用户**只提供了一张最终作品图**，或过程材料严重缺失 | 自动进行画面结构化分析、推断合理创作工作流、逆向生成复现垫图与阶段视觉结果、重构演进 Prompt 与参数建议。 |
| **Hybrid Mode（混合模式）** | 用户提供了部分材料（如仅有工具名与口述思路，无垫图和 Prompt） | 已有材料标记为 `[Verified]` / `[User-reported]`，缺失环节启动 Reconstruction 并严格标注 `[Reconstructed]`。 |

> **核心原则**：`Verified > User-reported > Reconstructed > Unknown`。任何真实材料永远优先于复现材料。

---

## 二、第一步：Final Artwork 结构化分析

当进入 Reconstruction Mode 时，Agent 首先对最终作品图执行多维度视觉与技术特征提取，生成内部结构化分析报告：

```yaml
artwork_analysis:
  theme: "作品核心题材与设计主题"
  subject: "画面核心主体（人物/角色/场景/物品形态及特征）"
  composition: "构图法则（三分法/黄金分割/对称/对角线/中心放射）"
  perspective: "视角与镜头景别（特写/中景/全景/俯视/仰视/广角/长焦透视）"
  depth_planes: "空间层次（前景遮挡/中景主体/远景氛围及景深虚化）"
  palette: "主色调、辅助色、对比色及色温倾向"
  lighting: "主光源方向、辅助光、边缘轮廓光、环境反射与明暗对比"
  materials_textures: "核心材质质感（如金属光泽/皮肤肌理/布料褶皱/手绘笔触/3D粘土）"
  visual_style: "艺术风格（如概念插画/赛博朋克/新中式国风/三维渲染/超写实摄影）"
  atmosphere: "画面情绪与意境氛围（如宏大叙事/幽静空灵/赛博潮酷）"
  text_ui_elements: "画面文字、排版、Logo 或设计装饰元素（是否涉及人工后期）"
  possible_generation_method: "合理的技术生成路径推断（如文生图迭代、图生图线稿控制、分层合成等）"
  possible_input_assets: "逆向合理的输入素材类型（如构图手绘草图、色彩大关系垫图、线稿底稿）"
```

> **禁止项**：不得仅凭视觉分析断定具体模型版本号（如“这必定是 Midjourney v6”），应客观描述为“生成式图像技术结合数字后期”。

---

## 三、第二步：Workflow 创作流程逆向推断

根据分析得出的作品特征，自动判断一套最契合该作品的创作流程骨架，**严禁千篇一律套用死板流水线**：

### 典型流程范式参考：

- **范式 A（草图约束 + 图生图线稿控制 + 人工后期）**：
  适用于构图严谨、特定形状要求高、有明确手绘线稿/版式需求的作品：
  `概念草图构思 → 逆向构图垫图 → 线稿控制生成初稿 (V1) → 提示词与重绘优化 (V2) → PS人工精修合成`

- **范式 B（文本创意发散 + 多轮生图迭代 + 细节深化）**：
  适用于概念设计、纯画面视觉探索、氛围感主导的作品：
  `主题概念构思 → 基础文生图探索 (V1) → 视觉问题修正与提示词深化 (V2) → 局部质感精修与最终出图`

- **范式 C（多元素拆解生成 + 数字拼贴与版面设计）**：
  适用于海报设计、视觉传达、包含丰富排版与装饰图层的作品：
  `主视觉背景生成 → 核心元素分层生成 → 色彩与光影统筹 → 字体设计与版式排版`

## 四、第三步：逆向生成输入素材（垫图）— Capability-Based Design

竞赛规则普遍要求“提供输入素材（垫图）”。当原始垫图缺失时，Skill 调用当前 Agent 环境可用的图像生成/编辑能力，以最终作品为基准，逆向生成 1～2 张符合创作逻辑的早期输入素材。

### 1. 逆向操作类型（Capability Matrix）

Agent 根据作品特征自适应调用：

| 能力操作 | 目标输出特征 | 适用场景 |
|---|---|---|
| `reference_to_sketch` | 灰度粗糙铅笔草图、结构辅助线、动态骨架 | 强调构图起源、人体比例把控 |
| `reference_to_lineart` | 简洁干净的黑白轮廓线稿 | 插画、国风、扁平设计、ControlNet 线稿输入 |
| `reference_to_composition_draft` | 粗略几何块面、镜头景深规划草稿 | 宏大场景、复杂建筑与透视空间 |
| `reference_to_color_block` | 模糊色块、明暗大关系涂抹稿 | 强调色彩意境、光影氛围定位 |
| `reference_to_grayscale_study` | 单色黑白素描关系稿、明度层次 | 重点突出光影对比、素描大关系 |
| `reference_to_simplified_input` | 核心主体简笔占位、符号化形状 | 标志、图标、极简图形设计 |

### 2. 逆向垫图的核心法则（铁律）

1. **必须更早、更粗糙、更简单**：
   - 逆向垫图**绝对不能**是一张与最终作品细节高度相似的高清成品图。
   - 它必须具备明显的“早期探索感”（如素描线条、未完成的色块、简化的几何形状）。
2. **严格标记 Evidence Level**：
   - 所有逆向生成的垫图在文件命名与文档中必须标注：
     `[Reconstructed] 逆向构图参考草图（基于最终作品逆向推断生成，用于呈现创作构图逻辑）`
3. **环境降级容错**：
   - 若当前运行环境没有图像生成工具（如不支持 `generate_image`），Skill 自动输出该垫图的**详细视觉规格描述与 Prompt 提示词**，指导用户在外部工具（如 SD/Canva/PS）中快速导出。

## 五、第四步：阶段性视觉结果链构建

竞赛文案明确要求：“文案须记录阶段性创作过程，通过截图+文字描述体现创作思路与流程，并提供对应环节的工具结果。”

Reconstruction Mode 自动组织一套合理的 **4～5 阶段视觉过程链**：

```text
[阶段 1 垫图输入] 01_reconstructed_sketch (构图线稿/色块草图)
       │
       ▼
[阶段 2 工具初稿] 02_reconstructed_generation_v1 (首轮AI生成初稿：构图成立，但细节粗糙/光影单一)
       │
       ▼
[阶段 3 迭代优化] 03_reconstructed_generation_v2 (调整Prompt/参数后二轮结果：细节丰富，但仍需微调)
       │
       ▼
[阶段 4 人工精修] 04_reconstructed_post_processing (图层分层修脏、局部锐化、色彩校准)
       │
       ▼
[阶段 5 最终成品] 05_final_user_artwork (用户提供的最终提交作品)
```

每个阶段都输出明确的“工具输出结果状态”与“存在问题/修改理由”，让评委看到清晰可信的演进脉络。

---

## 六、第五步：阶段性 Prompt 演进逆向重构

真实创作绝非一蹴而就。Prompt 必须按阶段呈现**演进逻辑**，并附带针对性的调整理由：

### 演进结构示例：

- **Prompt V1（基础概念与构图）**：
  - *目标*：确立主体、核心风格与视角大框架。
  - *Prompt*：`[主体大概念], [艺术风格定义], [主要构图]`
  - *对应工具结果*：主体生成完整，但背景空洞，光影缺乏层次，质感较平。

- **Prompt V2（光影强化与细节深化）**：
  - *调整理由*：解决 V1 光影平淡问题，增加环境光与特定材质细节描述。
  - *Prompt*：`[主体与动作修正], [艺术风格], [主光源与边缘轮廓光], [特定材质肌理], [空间景深]`
  - *对应工具结果*：光影质感显著提升，画面层次建立，局部出现杂乱瑕疵。

- **Prompt V3（负向修正与最终调优 / 局部重绘）**：
  - *调整理由*：引入负向提示词排除杂乱光斑，微调画面整体质感。
  - *Prompt*：`[精炼后的完整正向描述]` + `Negative: [针对性排除瑕疵词]`

> **反伪造底线**：所有复现 Prompt 必须醒目标注：  
> `【Reconstructed Prompt（复现建议）】本提示词系根据最终作品画面特征逆向推演，用于展示创作迭代思路，非创作现场原始历史记录。`

---

## 七、第六步：复现参数建议（Suggested Reconstruction Parameters）

若用户未提供原始配置参数，Agent 给出针对该画面复现的**推荐参数组合**：

```markdown
### 推荐复现参数（非历史实测值）
- 生成模式：图生图 (Image-to-Image / Lineart Control) 或 文生图 (Text-to-Image)
- 建议画面比例：16:9 / 3:4 / 1:1（依最终作品尺寸）
- 建议重绘幅度 (Denoising Strength)：0.55–0.70（若使用图生图）
- 建议采样步数 (Steps)：25–35 步
- 建议提示词引导系数 (CFG Scale)：6.0–8.0
- 建议分辨率基准：1024×1024 以上高清渲染
```

> **严格禁止**：不得虚构随机种子数值（Seed）！如无原始记录，Seed 项必须明确标注为“未记录（复现时建议使用随机种子 -1）”。

---

## 八、第七步：完整输出组织

将上述所有逆向成果无缝注入 Stage-Centric 结构，并在文档末尾附加《复现材料特别说明》：

> “说明：本文档中标记为 `[Reconstructed]` 的草图、阶段过程图、演进提示词及参数建议，由 AI 辅助分析系统根据创作者最终提交的作品进行逆向分析与工程复现，旨在完整阐明作品的设计逻辑、技术路径与可复现性，不作为创作当时保存的原始物理记录。”
