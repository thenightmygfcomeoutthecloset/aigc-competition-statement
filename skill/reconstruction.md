# Reconstruction Mode — 逆向重构模式执行规范

> 本文档定义在用户**仅提供最终作品图**或**过程材料严重缺失**时，Skill 如何自动逆向重构合理的 AIGC 创作流程、生成必要的复现素材、阶段结果、Prompt 演进与参数建议。

---

## 一、模式触发与执行铁律

### 1. 触发判定
当且仅当创作者**仅上传了一张最终作品图**，或明确告知未保存任何原始草图、Prompt、参数与过程截图时，自动启用本模式。

### 2. 执行铁律
1. **绝不中途停止，绝不强制逼问**：面对单张图片，Agent 严禁反复要求用户提供原始 Prompt 或工作流，必须自主启动全套逆向推演与材料生成。
2. **实际调用图像生成工具**：宿主环境有生图能力时，必须实际渲染过程图片文件，详见 [skill/image-generation.md](image-generation.md)；无生图能力时执行标准 Fallback，绝不编造虚假文件路径。
3. **真实性标示**：所有逆向生成的内容（草图、阶段图、演进 Prompt、建议参数）一律定级为 `[Reconstructed]`，严禁标记为 `[Verified]`。
4. **杜绝伪造软件界面**：可以生成草图、线稿、色块图与阶段生成图，但**绝对禁止生成模拟的 Photoshop 图层界面截图、ComfyUI 节点截图或 WebUI 历史界面**来伪充真实历史操作！

---

## 二、第一步：Final Artwork 结构化深度解构

Agent 首先对最终作品图执行多维度视觉与技术特征提取，生成内部结构化分析报告：

```yaml
artwork_analysis:
  theme: "作品核心题材与设计立意"
  subject: "画面核心主体（形态、动作、空间位置）"
  composition: "构图法则（三分法/黄金分割/对称/向心/对角线）"
  perspective: "视角与景别（特写/中景/全景；俯视/仰视/平视；广角/长焦透视）"
  depth_planes: "空间层次（前景遮挡/中景主体/远景氛围与景深关系）"
  palette: "色彩体系（主色、辅助色、强调色、明暗色温倾向）"
  lighting: "光影设计（主光源方向、辅助光、轮廓光、体积光、环境漫反射）"
  materials_textures: "核心材质肌理（金属反射/毛发细节/皮肤微晶/流体折射/布料褶皱）"
  visual_style: "艺术风格定位（如：国风水墨插画/赛博朋克概念设计/3D粘土渲染/超写实）"
  atmosphere: "整体情绪氛围（幽静空灵/宏大崇高/赛博潮酷）"
  text_ui_elements: "文字排版、Logo 或设计边框等人工痕迹（如有）"
  possible_generation_method: "技术路径推断（草图引导图生图 / 概念文生图多轮迭代 / 分层多元素合成）"
  possible_input_assets: "逆向合理的早期垫图类型（铅笔构图草稿、轮廓线稿、色彩大关系色块图）"
```

---

## 三、第二步：Workflow 创作管线逆向推断

根据分析得出的作品特征，自动判断一套最契合该作品的创作流程骨架，**严禁千篇一律套用死板流水线**：

- **范式 A（草图约束型管线）**：适用于造型严谨、构图精巧、具有明确轮廓秩序的作品：
  `概念构图草图规划 → 线稿控制基础生图 (V1) → 提示词与光影深化 (V2) → 最终出图`
- **范式 B（概念发散与多轮迭代型管线）**：适用于宏大场景、超现实氛围主导的作品：
  `主题概念探索 → 基础文生图粗胚 (V1) → 负向剔除与材质深化 (V2) → 最终成稿`
- **范式 C（多主体分层合成型管线）**：适用于复杂商业海报、视觉传达作品：
  `背景氛围生成 → 核心主体独立生成 → 元素合成拼贴 → 最终调整`

> **关于人工后期的特别规则**：若用户未说明做过后期处理，且画面中无明显人工排版设计，**绝不得强行声称使用了 Photoshop，更不得伪造假的 PS 图层截图**！此时应将流程如实定义为“纯 AI 具象生成直出流程”。

---

## 四、第三步：逆向垫图与阶段视觉链生成

详见 [skill/image-generation.md](image-generation.md)。

1. **垫图逆向生成**：
   - 调用可用生图能力（`reference_to_sketch`、`reference_to_color_block`、`reference_to_lineart` 等）；
   - 生成具有明显“早期探索感”的粗糙草稿；
   - 命名并保存在项目目录（如 `01_reconstructed_sketch.png`），标为 `[Reconstructed]`。
2. **阶段性 AI 结果生成**：
   - 生成 `02_reconstructed_generation_v1.png`，其完成度低于最终作品，且包含合理、可观察的阶段性视觉瑕疵（如光影欠缺、背景单薄）。

---

## 五、第四步：因果驱动的 Prompt 演进逆向设计

Prompt 必须具备清晰的**前后因果推演逻辑**，严禁生成无因果关系的重复文本：

```text
Prompt V1（基础概念与构图大框架）
  ↓
工具生成初稿 Output V1
  ↓
【发现阶段瑕疵】：如光影平淡、缺乏空间纵深、特定材质细节模糊
  ↓
【明确调整原因】：针对性引入主光源强化词、材质质感词，并加入负向提示词剔除杂斑
  ↓
Prompt V2（光影强化、材质深化与负向排除）
  ↓
工具生成优化稿 Output V2
```

> **标示规范**：所有复现 Prompt 必须标注：  
> `[Reconstructed Prompt | 复现建议]`，严禁写作“当时实际使用的原始 Prompt”。

---

## 六、第五步：推荐复现参数建议（Suggested Parameters）

若无原始参数记录，一律提供**用于复现该作品的建议参数范围**，绝不编造假数值：

| 参数项 | 推荐复现配置（非历史实测值） | 状态说明 |
|---|---|---|
| 生成模式 | 图生图 (Image-to-Image) 或 文生图 (Text-to-Image) | [Reconstructed] |
| 建议采样步数 (Steps) | 建议范围 25–35 步 | [Reconstructed] |
| 建议引导系数 (CFG) | 建议范围 6.0–8.0 | [Reconstructed] |
| 建议重绘幅度 (Denoising) | 建议范围 0.55–0.70（若使用图生图） | [Reconstructed] |
| 随机种子 (Seed) | **未记录（复现时建议使用随机种子 -1）** | **严禁编造任何具体数值** |

---

## 七、第六步：装配 Stage-Centric 结构与免责声明

将上述推演成果注入七大章节结构，并在文档末尾附加《复现材料特别说明》：

> **复现材料特别说明**：  
> 本说明文档中标记为 `[Reconstructed]` 的草图构图、阶段演进过程图、提示词演进及推荐配置参数，系因创作者创作过程中部分原始中间过程文件未作完整留存，由 AI 辅助分析系统根据最终作品的视觉与工程特征进行逆向工程分析和复现构建。其核心目的在于完整展示作品的技术路线、构思演进逻辑与工艺可复现性，并不代表创作当时保存的原始物理历史记录。
